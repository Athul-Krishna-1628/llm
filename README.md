- Clone repository using git clone https://github.com/Athul-Krishna-1628/llm.git
- updating local code - git pull

STEP 2 : UV 
- run 'uv init'
- run ' uv venv anynameforvenv'
    example : uv venv llm
- run uv pip install --python llm langchain langgraph langchain-core langchain-community mcp openai anthropic chromadb sentence-transformers
- activate venv 
    example : ./venv/scripts/activate
